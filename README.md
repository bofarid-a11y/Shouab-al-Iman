# Van Eenheid naar Ihsan

Deze statische website wordt gepubliceerd met GitHub Pages vanuit de hoofdmap van de `main`-branch:

https://bofarid-a11y.github.io/Shouab-al-Iman/

Wijzigingen worden zichtbaar nadat ze op `main` staan en GitHub Pages ze heeft verwerkt. Open `index.html` lokaal om de inhoud te bekijken.

## Beoordelingen

GitHub Pages verwerkt geen formulierinzendingen. De bestaande beoordelingsformulieren zijn daarom tijdelijk uitgeschakeld; ze versturen of bewaren geen gegevens. Om beoordelingen te verzamelen is een aparte formulierdienst of backend nodig. Configureer en test die dienst, inclusief privacy-informatie, voordat de formulieren weer worden ingeschakeld. De oorspronkelijke Netlify-formulierafhandeling werkt niet op GitHub Pages.

## Eigen domein

Voor een eigen domein zijn een geregistreerde domeinnaam en toegang tot de DNS-instellingen bij de domeinprovider nodig. Stel het domein eerst in onder **Settings → Pages → Custom domain** in GitHub en volg vervolgens de actuele DNS-instructies van GitHub voor het gekozen hoofddomein of subdomein. Activeer HTTPS zodra het certificaat beschikbaar is. Controleer het domein ook in de GitHub-accountinstellingen om het risico op domeinkaping te beperken.

Documentatie: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
